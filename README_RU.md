## Что такое ChillPass?

ChillPass — это **настольное приложение**, которое превращает ваши учебные материалы (PDF, Word, PPTX, TXT, MD) в **обучение в формате квеста**. Загрузите курс — ИИ-движок автоматически извлечёт экзаменационные темы, создаст структурированные уроки с разобранными примерами и адаптивные тесты — всё отсортировано по вероятности встретиться на экзамене.

Начиная с **v1.2.3**, ChillPass переработан в **веб-приложение браузерного типа**, упакованное в автономный исполняемый файл Windows через Node.js SEA (Single Executable Application). Без Electron и тяжёлых рантаймов — только один `chillpass.exe`, который запускает локальный HTTP-сервер и открывает браузер по умолчанию. Данные на 100% хранятся локально (IndexedDB + localStorage), приложение полностью работает офлайн.

**Как это работает:**

```
Загрузка материалов → ИИ извлекает темы → Строит путь квеста → Прохождение квестов
                                ↓
        Обязательно / Часто / Ознакомительно (три уровня приоритета)
                                ↓
      Объяснение тем → Примеры → Тесты → Заработок Chill-монет
                                ↓
                   Athena — ИИ-агент
        ┌──────────────┼──────────────┐
    Написание работ   Отчёты        Конспекты тем
        └──────────────┼──────────────┘
                Планирование подготовки
```

## Основные возможности

### Учебный движок в формате квеста

| Возможность | Описание |
|---------|-------------|
| **ИИ-извлечение тем** | DeepSeek анализирует материалы, извлекает экзаменационные темы и распределяет их по трём приоритетам |
| **Пакетная обработка** | PDF на 200+ страниц обрабатываются частями, параллельно и с дедупликацией — не пропустится ни одна страница |
| **Прогрессивная разблокировка** | Пройдите квест — откроется следующий. Каждый квест включает теорию, примеры и финальный тест |
| **Адаптивные тесты** | Один вопрос на страницу с навигацией по прогрессу. Ошиблись? Генерируется новый вопрос по той же теме — до полного усвоения |
| **Регенерация и пропуск** | Застряли? Бесплатно сгенерируйте новый вопрос по той же теме или потратьте 10 Chill-монет на пропуск |
| **Динамическая сложность** | Число вопросов зависит от приоритета — 4-5 для обязательных тем, 2 для ознакомительных |
| **Управление курсами** | Экспорт курса (вместе со всеми созданными квестами) в JSON для обмена, импорт курса друга, удаление ненужных курсов |
| **Детект дубликатов** | При импорте курса с существующим именем появится подтверждение замены — дубликатов больше не будет |

### Шесть типов вопросов + ИИ-проверка

```
┌──────────────────┬──────────────────────────────────────────────┐
│   Тип вопроса    │                   Поведение                  │
├──────────────────┼──────────────────────────────────────────────┤
│  Один вариант    │ 4 варианта, мгновенная проверка              │
│  Неск. вариантов │ 4-6 вариантов, минимум 2 верных, проверка    │
│  Вставить слово  │ Свободный ввод, ключевые слова + ИИ-проверка │
│  Краткий ответ   │ Свободный ответ, ИИ-оценка с эталоном        │
│  Расчётная задача│ Пошаговое решение, оценка каждого шага       │
│  Эссе            │ Развёрнутый ответ, оценка по структуре       │
└──────────────────┴──────────────────────────────────────────────┘
```

Неправильный ответ запускает **адаптивный повтор**:
- **Вопросы с выбором** → варианты перемешиваются, попробуйте снова
- **Вставка слова / краткий ответ** → ИИ генерирует совершенно новый вопрос по той же теме

### Локальная система аккаунтов

Полностью офлайн-система аккаунтов — без серверов, без входа, без слежки:

| Возможность | Описание |
|-----------|-------------|
| **Автосоздание** | Аккаунт по умолчанию создаётся при первом запуске, регистрация не нужна |
| **Профиль** | Никнейм, 12 эмодзи-аватаров на выбор, короткая подпись о себе |
| **Экспорт / импорт** | Аккаунт экспортируется в JSON-файл и переносится на новое устройство импортом |
| **Приватность** | Все данные аккаунта хранятся в localStorage браузера и никуда не отправляются |

### Athena — ИИ-агент

Athena — не просто чат-бот, а полноценный агент с **способностями**, **памятью** и **задачами**:

| Способность | Описание |
|-----------|-------------|
| **Свободные вопросы** | Контекстно-зависимый диалог на DeepSeek с опорой на ваши материалы |
| **Написание работ** | Структурированные академические работы — тема, объём, план и требования настраиваются |
| **Отчёты** | Лабораторные, исследовательские работы, рефераты — правильный формат и структура |
| **Конспекты тем** | Систематизация ключевых понятий по всем главам |
| **План подготовки** | Персональный план с учётом даты экзамена и слабых мест |
| **Управление способностями** | Автообнаружение + ручное добавление навыков, экспорт между устройствами |
| **Система памяти** | Уставная память (управляется вами) + текущая память (ведётся агентом) |
| **OCR изображений** | Фото → распознавание Tesseract.js → объяснение от ИИ |
| **Индикатор состояния** | Живая строка состояния: свободен / думает / выполняет задачу |

### Экономика Chill-монет

Виртуальная валюта, связывающая учёбу с мгновенным вознаграждением:

- **Заработок**: пройденные тесты (30-40 монет) + 1 монета за каждую минуту учёбы
- **Траты**: разблокировка квестов (30-40 монет) + пропуск вопросов (по 10 монет)
- **Отслеживание**: баланс показывается на дашборде, в боковой панели и на пути квестов с анимацией подпрыгивания

### Учительская рабочая станция

Отдельное пространство для учителей (включается в настройках — «Я учитель»):

- **Генерация вопросов ИИ** — 6 типов вопросов по материалам курса (один вариант, несколько вариантов, вставка слова, краткий ответ, расчёт, эссе), настройка сложности и количества (1-50, свободный ввод)
- **Умный подбор типа** — ИИ анализирует каждую тему и выбирает подходящий тип вопроса (формулы → расчёт, понятия → краткий ответ)
- **Умная группировка** — вопросы автоматически группируются по типу, группы сворачиваются
- **Полный просмотр** — каждый вопрос показывается целиком, с рендерингом формул KaTeX
- **Экспорт в PDF** — профессиональные экзаменационные работы:
  - Рамка с данными ученика (имя, номер, класс)
  - Баллы по каждому разделу
  - Линии для ответов на открытые вопросы
  - Отдельная страница с ключами и пошаговыми решениями расчётных задач
  - Рендеринг формул KaTeX при печати
- **Экспорт на 5 языках** — перед экспортом работа полностью переводится (китайский, английский, японский, корейский, русский)
- **Повторы и таймауты** — надёжные вызовы API: 3 повторных попытки, таймаут 90 секунд, динамический лимит токенов

### Системный трей и автообновление

| Возможность | Описание |
|-----------|-------------|
| **Иконка в трее** | Нативная иконка Windows-трея (на PowerShell) с «Открыть в браузере» и «Выход» — исчезает вместе с сервером |
| **Проверка обновлений** | Проверяет GitHub Releases; поддерживает тихий режим (автозагрузка + установка) и режим с окном прогресса (WinForms) |
| **Резерв через прокси** | При сбое прямой загрузки автоматически используется зеркальный прокси GitHub |
| **Проверка в приложении** | Проверка обновлений в один клик на странице настроек: «у вас последняя версия» или подтверждение автозагрузки и установки |
| **Оповещение о новой версии** | Карточка задач проверяет обновления при запуске; при обнаружении новой версии появляется постоянный баннер со скачиванием в один клик (при недоступности автообновления — скачивание через браузер) |

## Установка

### Скачать и установить (рекомендуется)

Перейдите в [Releases](https://github.com/Koipoppy/ChillPass-Web/releases) → скачайте `ChillPass-Setup-0.1.0.exe` → установите.

> Windows 10/11 (64 бит). Установка для текущего пользователя (без прав администратора). Ярлык на рабочем столе создаётся автоматически. При обновлении данные сохраняются.

### Сборка из исходников

```bash
git clone https://github.com/Koipoppy/ChillPass-Web.git
cd ChillPass-Web
npm install

# ── Режим разработки (только браузер) ──
npm run dev                  # Dev-сервер Vite: http://localhost:5173

# ── production-сборка ──
npm run build                # Сборка Vite → dist/

# ── Сборка автономного исполняемого файла ──
# Требуется: Node.js 22+ (SEA), NSIS 3.x (установщик)
node installer/build-sea.mjs              # Сборка chillpass.exe через Node.js SEA
makensis installer/installer.nsi          # Упаковка exe в NSIS-установщик
```

## Быстрый старт

**1.** Откройте **Настройки → API** и вставьте свой [ключ DeepSeek API](https://platform.deepseek.com/api_keys)

**2.** Нажмите **Импорт материалов** → выберите файлы PDF/Word/PPTX → назовите курс → дождитесь, пока ИИ построит квесты

**3.** Перейдите в **Квесты** → начните с первого → изучите теорию → разберите примеры → пройдите тест

**4.** Зарабатывайте Chill-монеты за тесты и время учёбы и тратьте их на разблокировку квестов или пропуск сложных вопросов (по 10 монет). Застряли? Бесплатно сгенерируйте новый вопрос по той же теме.

**5.** Откройте **Athena** → спрашивайте что угодно или запустите задачу (работа, отчёт, конспект, план) → получите структурированный результат

**6.** (Для учителей) Включите **режим учителя** в настройках → откройте **учительскую рабочую станцию** → сгенерируйте вопросы → экспортируйте PDF

**7.** Укажите дату экзамена на дашборде и следите за обратным отсчётом.
