## ChillPass とは？

ChillPass は、授業資料（PDF・Word・PPTX・TXT・MD）を**クエス形式の学習体験**に変える**デスクトップアプリ**です。資料をアップロードすると、AI エンジンが試験ポイントを自動抽出し、例題付きの構造化レッスンとアダプティブな小テストを生成します。すべての内容は試験に出る可能性の高い順に並んでいます。

**v1.2.3** から、ChillPass は Node.js SEA（Single Executable Application）で単一の Windows 実行ファイルにパッケージされた**ブラウザ型 Web アプリ**として再構築されました。Electron も重いランタイムも不要 —— ローカル HTTP サーバーを起動して既定のブラウザを開く、たった一つの `chillpass.exe` だけ。データは 100% ローカル（IndexedDB + localStorage）に保存され、完全オフラインで動作します。

**ワークフロー：**

```
資料アップロード → AI が試験ポイントを抽出 → クエストパス生成 → ひとつずつ攻略
                                ↓
        必考 / 頻出 / 了解（3 段階の優先度）
                                ↓
      知識ポイント解説 → 例題 → 小テスト → Chill コイン獲得
                                ↓
                   AI エージェント Athena
        ┌──────────────┼──────────────┐
     論文執筆        レポート作成     知識まとめ
        └──────────────┼──────────────┘
                復習プラン作成
```

## コア機能

### クエスト型学習エンジン

| 機能 | 説明 |
|---------|-------------|
| **AI 試験ポイント抽出** | DeepSeek が資料を分析し、試験ポイントを抽出して 3 段階の優先度に分類 |
| **バッチ処理** | 200 ページ超の PDF を分割抽出・並列処理・重複排除と統合 —— 1 ページも漏れません |
| **漸進的アンロック** | ひとつのクエストをクリアすると次が解放。各クエストには知識ポイント・例題・クリアテスト付き |
| **アダプティブ小テスト** | 1 問 1 ページ、進捗ナビ付き。間違えたら同じポイントの全新問題を再生成し、習得できるまで繰り返し |
| **再生成とスキップ** | 手こずっていますか？同じポイントの新しい問題を無料で再生成、または 10 Chill コインでスキップ |
| **動的難易度** | 問題数は優先度に応じて変動 —— 必考ポイントは 4-5 問、了解レベルは 2 問 |
| **コース管理** | コースは生成済みクエストごと JSON にエクスポートして共有でき、友人のコースのインポートや不要なコースの削除も可能 |
| **重複コース検出** | 同名コースのインポート時は置き換え確認を表示 —— 重複コースはもう生まれません |

### 6 種類の問題形式 + AI 採点

```
┌────────────────┬──────────────────────────────────────────────┐
│    問題形式     │                  動作                         │
├────────────────┼──────────────────────────────────────────────┤
│  単一選択       │ 4 択、即時に正誤フィードバック                  │
│  複数選択       │ 4-6 択、正解 2 つ以上、提出後に採点              │
│  穴埋め         │ 自由入力、キーワードマッチ + AI 採点             │
│  簡答           │ 自由記述、AI 採点、参考答案付き                  │
│  計算問題       │ 段階的な解答、AI が各ステップを採点              │
│  論述           │ 長文記述、AI が構成に沿って採点                  │
└────────────────┴──────────────────────────────────────────────┘
```

誤答すると**アダプティブな再挑戦**が発生します：
- **選択問題** → 選択肢をシャッフルして再挑戦
- **穴埋め / 簡答** → 同じポイントの全新問題を AI が再生成

### ローカルアカウントシステム

完全オフラインのアカウント体系 —— サーバーなし、ログインなし、トラッキングなし：

| 機能 | 説明 |
|-----------|-------------|
| **自動作成** | 初回起動時にデフォルトのローカルアカウントを自動作成、登録不要 |
| **プロフィール編集** | ニックネーム設定、12 種類の絵文字アバターから選択、自己紹介の追加 |
| **エクスポート / インポート** | アカウントを JSON ファイルにエクスポートし、新しい端末でインポートするだけで移行 |
| **プライバシー最優先** | すべてのアカウントデータはブラウザの localStorage に保存され、外部には一切送信されません |

### Athena —— AI エージェント

Athena は単なるチャットボットではなく、**能力**・**記憶**・**タスクワークフロー**を備えた本格的なエージェントです：

| 能力 | 説明 |
|-----------|-------------|
| **自由質問** | DeepSeek 駆動の文脈認識対話。あなたのコース資料に基づいて回答 |
| **論文執筆** | 構造化された学術論文の生成 —— テーマ・字数・構成・要件をすべてカスタマイズ可能 |
| **レポート作成** | 実験レポート、調査レポート、読書レポート —— 規定の形式で完全な構成 |
| **知識まとめ** | 章を横断して核心概念を体系的に整理 |
| **復習プラン** | 試験日と弱点に基づく個別の復習計画を作成 |
| **能力管理** | 自動発見 + 手動追加のスキル、端末間でエクスポート可能 |
| **記憶システム** | 憲章メモリ（ユーザーが管理するルール）+ フローメモリ（エージェントが管理する文脈） |
| **画像 OCR** | 写真 → Tesseract.js で認識 → AI が解説 |
| **状態インジケーター** | 待機中 / 思考中 / タスク実行中をリアルタイム表示 |

### Chill コイン経済

学習と即時報酬をつなぐ仮想通貨：

- **獲得**：小テストのクリア（30-40 コイン）+ 学習時間 1 分につき 1 コイン
- **消費**：クエストの解放（30-40 コイン）+ 小テスト問題のスキップ（1 問 10 コイン）
- **追跡**：ダッシュボード・サイドバー・クエストパスに残高をリアルタイム表示、バウンスアニメーション付き

### 教師ワークスペース

教師のための独立したワークスペース（設定 →「私は教師」で有効化）：

- **AI 出題** — コース資料から 6 種類の問題を生成（単選・複数選択・穴埋め・簡答・計算・論述）。難易度と問題数（1-50、自由入力）を調整可能
- **スマートな問題形式マッチング** — AI が各試験ポイントを分析し、最適な問題形式を自動選択（公式は計算問題、概念は簡答問題に）
- **スマートグループ化** — 問題は形式ごとに自動グループ化、各グループは折りたたみ可能
- **完全プレビュー** — 各問題を完全表示、KaTeX 数式レンダリング対応
- **PDF エクスポート** — プロフェッショナルな試験問題を生成：
  - 枠付き受験者情報欄（氏名・学籍番号・クラス）
  - 合計点付きのセクション別配点タイトル
  - 記述式の解答線
  - 計算問題の解答手順付きの別紙解答ページ
  - 印刷出力での KaTeX 数式レンダリング
- **5 言語でのエクスポート** — エクスポート前に全文翻訳（中国語・英語・日本語・韓国語・ロシア語）
- **リトライとタイムアウト** — 堅牢な API 呼び出し：3 回リトライ、90 秒タイムアウト、動的トークン上限

### システムトレイと自動更新

| 機能 | 説明 |
|-----------|-------------|
| **システムトレイアイコン** | ネイティブ Windows トレイアイコン（PowerShell 実装）。「ブラウザで開く」と「終了」に対応 —— サーバー終了時は自動的に消えます |
| **更新の自動チェック** | GitHub Releases の新バージョンをチェック。サイレントモード（自動ダウンロード + インストール）と GUI モード（WinForms 進捗ダイアログ）に対応 |
| **プロキシフォールバック** | 直接ダウンロードに失敗した場合、GitHub プロキシミラーへ自動切り替え |
| **アプリ内更新チェック** | 設定ページからワンクリックで更新をチェック。最新版なら「更新不要」と表示し、新バージョンがあればダイアログで確認して自動ダウンロード＆インストール |
| **新バージョン通知** | タスクカードが起動時に更新を自動チェックし、新バージョンを検出すると常時表示のバナーとワンクリックダウンロードを提供（自動更新が利用できない場合はブラウザダウンロードへフォールバック） |

## インストール

### ダウンロードしてインストール（推奨）

[Releases](https://github.com/Koipoppy/ChillPass-Web/releases) にアクセス → `ChillPass-Setup-0.0.9.exe` をダウンロード → インストール。

> Windows 10/11（64 ビット）。ユーザーごとのインストール（管理者権限不要）。インストール後にデスクトップショートカットを自動作成。更新時もデータは保持されます。

### ソースからビルド

```bash
git clone https://github.com/Koipoppy/ChillPass-Web.git
cd ChillPass-Web
npm install

# ── 開発モード（ブラウザのみ）──
npm run dev                  # Vite 開発サーバー http://localhost:5173

# ── 本番ビルド ──
npm run build                # Vite ビルド → dist/

# ── 単一実行ファイルのビルド ──
# 必要環境：Node.js 22+（SEA）、NSIS 3.x（インストーラー）
node installer/build-sea.mjs              # Node.js SEA で chillpass.exe をビルド
makensis installer/installer.nsi          # exe を NSIS インストーラーにパッケージ
```

## クイックスタート

**1.** **設定 → API** を開き、[DeepSeek API キー](https://platform.deepseek.com/api_keys)を入力

**2.** **資料インポート**をクリック → PDF/Word/PPTX ファイルを選択 → コースに名前を付け → AI がクエストを生成するのを待つ

**3.** **クエスト**へ進む → 第 1 関からスタート → 知識ポイントを読む → 例題を学ぶ → 小テストに合格

**4.** 小テストと学習時間で Chill コインを獲得し、クエストの解放や難問のスキップ（1 問 10 コイン）に使用。手こずったら、同じポイントの新しい問題を無料で再生成。

**5.** **Athena** を開く → 自由に質問、またはタスクを開始（論文・レポート・まとめ・プラン）→ 構造化された成果物を取得

**6.**（教師）設定で**教師モード**を有効化 → **教師ワークスペース**を開く → 問題を生成 → PDF エクスポート

**7.** ダッシュボードで試験日を設定し、カウントダウンを確認。
