# ChillPass 新手引导 + Token 统计实现计划

## 目标

1. **新手引导**：为首次使用的用户提供「配置 API Key → 导入课件 → AI 生成关卡」的完整引导，采用**欢迎向导 + 悬浮任务卡**两段式设计，API Key 跳转现有 `/settings/api` 页面配置。
2. **引导弹窗内嵌语言选择**：欢迎页可直接切换 5 种界面语言，选择后立即生效。
3. **Token 消耗统计**：在 API 配置页展示 DeepSeek token 消耗（累计/今日/近 7 日 + 调用次数）。

## Part 1：新手引导

### 1.1 触发与检测（新增 `src/stores/onboardingStore.ts`）

- Zustand persist store，key：`chillpass-onboarding`，状态：`stage: 'welcome' | 'active' | 'done' | 'skipped'`，默认 `'welcome'`。
- Actions：`startGuide()`（welcome→active）、`completeGuide()`（→done）、`skipGuide()`（→skipped）、`restartGuide()`（done/skipped→active，供设置页重看）。
- **欢迎弹窗显示条件**（防打扰老用户）：`stage === 'welcome'` **且** `apiKey === ''` **且** `courses.length === 0` 三者同时满足。
- **引导步骤不落库，全部从真实状态实时推导**（在任何页面手动操作都能正确打勾）：
  | 步骤 | 完成条件 |
  |---|---|
  | ① 配置 API Key | `settingsStore.apiKey` 非空 |
  | ② 导入课件，创建课程 | 任一课程 `files.length > 0 \|\| rawText` 非空 |
  | ③ 等待 AI 生成关卡 | 任一课程 `status === 'ready'`；生成中用 `generatingLessons / generationProgress` 显示实时进度（Dashboard/Sidebar 已消费同样状态） |

### 1.2 欢迎向导弹窗（新增 `src/components/onboarding/WelcomeModal.tsx` + `.module.css`）

3 页滑动玻璃弹窗（520px，圆点指示器 + 上一步/下一步，纯 CSS 动画）：

1. **欢迎页**：应用图标 + 「你的 AI 学习伙伴」+ 隐私说明（数据 100% 本地）+ **语言选择区**。
2. **三步概览页**：① 配置 Key → ② 导入课件 → ③ AI 生成闯关课程。
3. **开始行动页**：主按钮「去配置 API」→ `startGuide()` + `navigate('/settings/api')`；弹窗关闭后悬浮任务卡接管。

每页右下角有「跳过引导」（`skipGuide()`）。

**语言选择**（新增需求）：欢迎页下方放 5 个语言芯片（复用 SettingsPage 的 `langGrid/langOption` 样式模式，直接用 `LANGUAGES` 的 flag+label，芯片文案是各语言原生名无需翻译），点击即调 `languageStore.setLanguage(code)` —— `useT()` 订阅组件全部自动重渲染，**弹窗自身文案随选随切**。

### 1.3 悬浮任务卡（新增 `src/components/onboarding/GuideCard.tsx` + `.module.css`）

- 固定视口右下角（`fixed; right: 24px; bottom: 24px`），liquid-glass 卡片约 320px，**z-index: 990**（高于页面内容、低于现有弹窗层 1000/10000）。
- 头部「🎯 新手引导」+ 折叠/展开 + 关闭（跳过）；步骤列表（编号圆圈/对勾），当前步骤展开显示说明 + 行动按钮：
  - ①「去配置 →」→ `/settings/api`
  - ②「去导入课件 →」→ `/upload`（新用户无课程时 UploadPage 默认 create 模式，原生兼容）
  - ③ 生成中显示进度条（`current/total`）
- **完成态**：三步全勾 → 🎉 完成态，列出进阶功能提示（闯关冲刺/错题本/Athena 各一句），主按钮「开始闯关冲刺」→ `navigate('/lessons')` + `completeGuide()`。
- 可折叠成小徽章。

## Part 2：Token 消耗统计（API 配置页）

### 2.1 记账 store（新增 `src/stores/tokenStore.ts`）

- Zustand persist，key：`chillpass-token-stats`：
  - `total: { prompt, completion, total }` 累计 tokens
  - `daily: Record<'YYYY-MM-DD', { prompt, completion, total, calls }>` 按本地日期记账（近 7 日图表数据源）
  - `callCount` 累计调用次数
  - `recordUsage(u: { prompt_tokens, completion_tokens, total_tokens })`：更新累计 + 当日条目
  - `resetStats()`：清零
- 统计口径：仅统计本浏览器发起的成功调用（localStorage 本地数据）。

### 2.2 埋点（修改 `src/services/deepseek.ts`）

- **非流式 `callDeepSeek`**（第 51 行处）：成功响应后读 `data.usage`，调 `recordUsage`。重试中失败的请求不记账，成功那次只记一次。
- **流式 `callDeepSeekStream`**：请求体增加 `stream_options: { include_usage: true }`（DeepSeek/OpenAI 兼容约定，usage 在最后一个 chunk）；在 SSE 解析循环里检测 `parsed.usage` 存在即记账。若 API 未返回 usage 则跳过（防御式，不影响现有功能）。

### 2.3 展示 UI（修改 `src/pages/settings/ApiSettings.tsx`）

在现有 Key 配置区块下方新增 liquid-glass 统计卡片：

- **累计消耗**：总 tokens 大数字 + prompt/completion 明细、累计调用次数
- **今日消耗**：当日 tokens
- **近 7 日柱状图**：纯 CSS flex 小柱（高度按最大值归一化），无图表库
- **清除统计**按钮：`window.confirm` 确认（与 SettingsPage 现有确认风格一致）
- 文案走 i18n（`tokens.*` keys）

## 边界情况

- **老用户升级**：有 key 或有课程 → 欢迎弹窗被启发式拦截，不显示。
- **引导中刷新页面**：步骤状态实时推导不丢失；后台生成若因刷新中断，任务卡进度停住，用户可按提示回「导入课件」增量导入补全（现有机制）。
- **流式响应无 usage**：防御式跳过记账，不影响对话。
- **每日跨天**：按本地日期 `YYYY-MM-DD` 记新键，旧键保留供 7 日图查询，超过 7 日的键在图表渲染时忽略（不做删除，数据量可忽略）。
